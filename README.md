# forest-fire-cellular-automata
Forest fire spread simulation in MATLAB using cellular automata, with wind effects.
This project models how a forest fire spreads using a cellular automaton in MATLAB. The forest is a 100×100 grid of cells that are empty, healthy, burning, or burnt. At each time step, a healthy tree ignites with 80% probability if two or more of its eight neighbors (the Moore neighborhood) are burning. A wind factor adds 20% to the ignition chance in one direction, which makes the fire spread unevenly. The repository contains the MATLAB code, the simulation videos, and the presentation slides.
